# Utilities

Files:

- `allowed_words.py`: vocabulary constraints for generation.
- `checkpoint_manager.py`: checkpoint save/load helpers.
- `distributed_utils.py`: distributed-training utilities.
- `generation_utils.py`: generation helpers used by inference scripts.
- `loss_utils.py`: loss helpers for SFT/DPO training.
- `misc.py`: shared small utilities.
- `scheduler_utils.py`: learning-rate scheduler helpers.
- `training_recorder.py`: training metric recorder.
