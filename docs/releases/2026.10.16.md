# PolyTamGen 2026.10.16

This release accompanies
[Polypharmacological Target-Aware Molecule Generation](https://doi.org/10.1093/bioinformatics/btag766)
in Bioinformatics. The companion data, models, and revised results are in
[Zenodo](https://doi.org/10.5281/zenodo.23417382).

The README now includes the article, original framework figure, citation,
installation prerequisites, editable install, and a sampled inference example.

The reproduction scripts use `AvgDock < -8.18` for the main strict-success
metric and retain `-7.0` as an explicit sensitivity setting. The verifier
checks the revised rank-matched target-conditioning results and writes
reports outside the input results tree. Serial table generation releases
each split before loading the next.

The updated results archive contains the revised tables, conditioning
outputs, and a full verification report. Raw generations and docking scores
are unchanged. The data archive, base language model, and DPO checkpoint
are also unchanged; no training, generation, or docking was rerun.
