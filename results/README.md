# Results

Full result artifacts are distributed outside git as
four `polytamgen_full_results.tar.xz.part01` through `.part04` volumes.
[Assemble them](../ASSETS.md#where-to-extract) into
`polytamgen_full_results.tar.xz` before extracting.

For the command examples in this repository, extract the archive from
`source/pp2d/` so it creates:

```text
source/pp2d/results/
```

The archive contains raw generations, scored molecule files, figures,
supplement artifacts, and analysis inputs used by the paper-alignment scripts.
